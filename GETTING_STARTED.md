# Getting Started with FrictionlessAuthLayer

Welcome! This guide will help you get FrictionlessAuthLayer up and running in minutes.

## 🚀 Quick Setup (5 minutes)

### Step 1: Install Dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

### Step 2: Configure Environment

```bash
cp .env.example .env
```

Edit `.env` and update these critical values:

```env
# IMPORTANT: Change these in production!
AUTH_SECRET="change-this-to-a-random-32-char-secret"
WEBHOOK_SIGNING_SECRET="change-this-webhook-secret"

# SmartHooks Integration (get from Vantrakticks)
SMARTHOOKS_WEBHOOK_URL="https://smarthooks.vantrakticks.com/api/event"
SMARTHOOKS_API_KEY="your-api-key-here"
```

### Step 3: Initialize Database

```bash
npx prisma generate
npx prisma db push
```

This creates a `prisma/dev.db` SQLite database.

### Step 4: Start Development Server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## 🎯 Your First Integration

### Example: Setting Up Stripe

Let's configure Stripe for a project. You'll need:
- Stripe Secret Key
- Stripe Publishable Key
- Stripe Webhook Secret

#### 1. Create a Project (via API)

```bash
curl -X POST http://localhost:3000/api/projects \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My SaaS App",
    "slug": "my-saas-app",
    "accountId": "your-account-id"
  }'
```

**Response:**
```json
{
  "project": {
    "id": "clx123abc",
    "name": "My SaaS App",
    "slug": "my-saas-app"
  }
}
```

#### 2. Add Stripe Integration

```bash
curl -X POST http://localhost:3000/api/integrations \
  -H "Content-Type: application/json" \
  -d '{
    "projectId": "clx123abc",
    "accountId": "your-account-id",
    "type": "stripe",
    "credentials": {
      "secret_key": "sk_test_xxx",
      "publishable_key": "pk_test_xxx",
      "webhook_secret": "whsec_xxx"
    }
  }'
```

#### 3. Generate ENV File

```bash
curl http://localhost:3000/api/env/generate?projectId=clx123abc
```

**Response:**
```json
{
  "content": "# Generated by FrictionlessAuthLayer\nSTRIPE_SECRET_KEY=\"sk_test_xxx\"\n...",
  "filename": ".env.my-saas-app"
}
```

Save this to your application's `.env` file!

#### 4. Use in Your App

Copy the Stripe integration code:

```bash
curl http://localhost:3000/api/snippets/generate?projectId=clx123abc&type=stripe
```

Paste the snippet into your app and you're done!

## 📋 Common Use Cases

### Use Case 1: Email + Password Signup with Welcome Email

```typescript
import { SendGridIntegration } from '@/lib/integrations/sendgrid'
import { emitEvent } from '@/lib/webhooks/smarthooks'

async function handleSignup(email: string, password: string, name: string) {
  // 1. Create user in your database
  const user = await createUser({ email, password, name })

  // 2. Send welcome email
  const sendgrid = await SendGridIntegration.fromProject('your-project-id')
  await sendgrid.sendWelcomeEmail({
    to: user.email,
    name: user.name,
    verificationUrl: `https://yourapp.com/verify?token=${user.verificationToken}`
  })

  // 3. Emit event to SmartHooks
  await emitEvent('user.signup', 'your-project-id', {
    userId: user.id,
    email: user.email,
    name: user.name,
    signupMethod: 'email'
  }, user.id)

  return user
}
```

### Use Case 2: Stripe Subscription Checkout

```typescript
import { StripeIntegration } from '@/lib/integrations/stripe'

async function createSubscriptionCheckout(
  email: string,
  priceId: string
) {
  const stripe = await StripeIntegration.fromProject('your-project-id')

  // Create checkout session
  const session = await stripe.createCheckoutSession({
    priceId: priceId,
    successUrl: 'https://yourapp.com/success',
    cancelUrl: 'https://yourapp.com/pricing',
    customerEmail: email
  })

  // Redirect user to Stripe
  return session.url
}
```

## 🐛 Troubleshooting

### Issue: Prisma client errors

```bash
# Regenerate Prisma client
npx prisma generate
```

### Issue: Database connection errors

```bash
# Check DATABASE_URL in .env
echo $DATABASE_URL

# Test database connection
npx prisma db push --preview-feature
```

### Issue: Webhook delivery failures

Check the `WebhookEvent` table:

```sql
SELECT * FROM WebhookEvent WHERE status = 'failed' ORDER BY createdAt DESC;
```

Common causes:
- Invalid `SMARTHOOKS_API_KEY`
- Network connectivity issues
- Incorrect webhook URL

### Issue: Decryption errors

This means `AUTH_SECRET` changed after credentials were encrypted.

**Solution**: Re-add your integrations with new credentials.
